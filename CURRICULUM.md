# Rooftop Radio curriculum mapping

Audience: Hebrew-speaking Israeli grade-7 learners, with optional use by grade-8 learners revisiting this material. Scope is comprehension and application of written English directions and comparisons during movement. It does not assess spoken English or productive grammar. No validated learning gains or official approval are claimed.

Source evidence is preserved in `docs/curriculum/`. The following fixtures are original game writing, not Workbook quotations. Fixtures below match the reviewed content module. World consequences still require movement and browser verification before release.

Workbook source limits matter. The comparison module distinguishes measured features from preference, and the route-choice module does not make every longer route safe or universally preferable. Game geometry and English must expose the actual width/parcel condition rather than invent a general rule.

Hebrew help and vocabulary are on demand. Task-bearing English is explicitly LTR. Planning, reading, translations and replay pause medal time. Minimal local events must distinguish first unaided decisions, vocabulary, solution hints, retries and transfer. Ordinary vocabulary support remains available for transfer, but solution hints do not. Movement medals and comprehension evidence remain separate.

## Implementation reconciliation

Content/rules review: fixtures match the agreed content (Ch1 uses “Tune” so the broad alternate route also follows the task). Independent semantic tests verify compass truth, ordered tuning, stale evidence rejection and café/receiver reassignment. Input-only simulation tests exercise all five contracts, emitted route evidence, a parcel drop and replacement, direct glide and a broad no-jump route. Browser playtests, rendered landmark clarity, touch and Tripo animation remain separate acceptance checks. These tests establish simulated solvability, not learning gains.


The first task does not require a specific movement technique: its English names the relay by relation. Onboarding teaches the direct jump/glide separately, and that satisfying move is tested within 30 simulated seconds. The broad alternate route therefore remains a legitimate solution.
